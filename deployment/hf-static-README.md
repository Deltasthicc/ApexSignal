# ApexSignal

This public build is the interactive, fixture-backed ApexSignal judge demo.
The circuit atlas uses source-derived centerline geometry; incident, radio, and
assessment responses are compiled from the repository's contract fixtures and
are labeled as fixture data in the interface.

Source: [github.com/Deltasthicc/ApexSignal](https://github.com/Deltasthicc/ApexSignal)
