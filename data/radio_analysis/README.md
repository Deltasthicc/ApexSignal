# ⚠️ Placeholder output — not real curated incidents

The 20 `.json` files in this directory are `RadioAnalysisOutput` records
generated by `services/radio_ai/scripts/generate_radio_analysis.py`
against the 20 clips in `services/radio_ai/human_labels.csv`, on
2026-08-12.

**`incident_id` in every one of these files is the raw dataset filename
stem** (e.g. `2018_Australian_Grand_Prix_DANRIC01_3_20180325_170323`),
not a real `INC-xxx` id. Workstream A/Jagrav's `data/incident_manifest.json`
does not exist yet, so there is no real incident to attach these to —
these ids are stand-ins so radio_ai's output-writing path could be
exercised end-to-end before that manifest exists.

**If you're on core_api or another workstream and encounter these:**
do not treat them as real incidents. `core_api` will (correctly) 404
on any of these ids until the real manifest exists and radio_ai
re-generates output against real `INC-xxx` ids. That 404 is expected
behavior, not a bug to work around.

This directory is gitignored going forward (see root `.gitignore`) so
future placeholder/test runs don't get committed by accident — this
one snapshot is here deliberately, once, so the shape of real output
is visible before the real pipeline exists.
